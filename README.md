# 🧡 Luqui — Sales Website WD

A modern sales website for **Luqui web Dashboard**, a financial intelligence ecosystem designed to help people understand, organize, and make better decisions with their money.

This project showcases Luqui's visual identity, product experience, and digital ecosystem through a responsive and interactive web interface.

## 🚀 Project

This website is part of the Luqui ecosystem and serves as the public-facing sales experience for its digital products and financial tools.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Responsive Web Design

## 🌱 Vision

Luqui goes beyond personal finance. The long-term vision is to build an ecosystem around financial intelligence, including personal finance, investments, business finance, AI-powered tools, and eventually a dedicated application.
